# Manager VPN — bản phát hành

Kho này chỉ chứa **bộ cài** Manager VPN. Mã nguồn không nằm ở đây.

- Đang dùng Manager VPN: mở tool, có bản mới thì tool tự báo, bấm **Cập nhật ngay** là xong.
- Cài mới hoặc tool hỏng không mở được: tải `Manager-VPN_..._x64-setup.exe` ở **[Releases](../../releases/latest)** rồi chạy.

Bộ cài được ký số. Tool chỉ tự cài bản đúng chữ ký của LVC.
